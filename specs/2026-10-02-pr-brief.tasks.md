- **D1:** `dropped_items` = whole items dropped + invalid refs removed from kept risks.
- **D2:** linked issue = first same-repo issue in the PR description, in **text order**. If every ref is cross-repo → missing "issue in another repository".
- **D3:** doc order = enabled agents by `created_at`, `id`; per agent, `resolveRunDocSet` order (skills where link and skill are both enabled, by `agent_skills.order`, then skill id). First occurrence wins.
- **D4:** Intent is never cut. Its 600-token cap is a budget allowance.
- **D5:** the Intent and Blast cards sit in the brief grid in every state.
- **D6:** the stored brief has `intent`/`blast`/`history` = null.
- **D7:** output bounds are defined in Zod, with post-parse enforcement if the provider rejects a keyword. A bound failure is a schema failure, never a re-prompt.
- **D8:** deep link `?tab=diff&file=<encoded>&line=<n>`.
- **Budget (AC-13):** at most 12,000 tokens (`cl100k_base`).
  - Caps, measured on the wrapped text:

    | Section | Cap (tokens) |

    | title + description | 1,500 |
    | issue | 1,200 |
    | Intent | 600 |
    | blast summary + callers (≤ 60) | 1,400 |
    | diff stats (≤ 200 files) | 2,300 |
    | specs | 4,000 |

  - The caps add up to 11,000, which leaves about 1,000 tokens for the whole system message.
